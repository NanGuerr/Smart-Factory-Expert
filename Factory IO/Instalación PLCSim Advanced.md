# 🛠️ PLCSim Advanced - Instalación

La instalación de este software es exactamente igual a la que vimos en PLCsim común. ¡Ten en cuenta que esto es solamente informativo y **no es necesario** descargar PLCsim Advanced para realizar este curso! 💡

---

### 📥 Descarga de PLCsim Advanced V6.0
[Click aquí para descargar](https://support.industry.siemens.com/)

---

### ⚙️ Requisitos – S7-PLCSIM Advanced V6.0

• **OS:** Windows 10 o Windows 11 (64 bits). 💻
• **Procesador:** Multinúcleo (recomendado i5 o superior). 🚀
• **RAM:** 8 GB mínimo (16 GB recomendado para múltiples CPUs virtuales). 🧠
• **Almacenamiento:** 5–10 GB de espacio libre en disco. 💾
• **Conectividad:** Interfaz de red Ethernet habilitada. 🌐
• **Software:** TIA Portal compatible con la versión V6.0. 🛠️
• **Licencias:** Automation License Manager instalado (si es la versión 6.2 SP2 o superior, mejor). 🔑
• **Permisos:** Administrador en el sistema. 🛡️

---

### 💿 Instalación desde archivo ISO

1. **Descargar:** Obtén la imagen ISO desde el portal oficial de Siemens. 📥
2. **Montar:** Haz clic derecho sobre el archivo ISO y selecciona “Montar” (Windows creará una unidad virtual automáticamente). 🖱️
3. **Acceder:** Abre la unidad virtual creada. 📂
4. **Ejecutar:** Ejecuta `Start.exe` o `Setup.exe` como administrador. ⚙️
5. **Licencia:** Acepta los términos de licencia. 📝
6. **Destino:** Selecciona la carpeta de destino (recomendado dejar la predeterminada). 📁
7. **Finalizar:** Completa el asistente de instalación. ✅
8. **Reiniciar:** Reinicia el equipo si el instalador lo solicita. 🔄
9. **Activación:** Abre *Automation License Manager* y activa la licencia de prueba incluida. 🔑

---

### 🎉 ¡Listo!
Ya tienes todo instalado. Ten en cuenta que el **PLCsim Advanced** se ejecuta como una aplicación aparte. Por lo tanto, debes abrirla primero para configurar tu PLC virtual. Luego, en el TIA Portal, cuando realices la conexión al PLC, utiliza el adaptador virtual de PLCsim Advanced que se instala en tu PC. 🖥️✨
