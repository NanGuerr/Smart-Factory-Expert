# 🏭 Protocolos de Comunicación para Factory I/O

Factory I/O es un simulador 3D diseñado para la automatización industrial, que permite construir escenas de fábrica y conectarlas con PLCs u otras tecnologías mediante protocolos de comunicación estándares. 🌐

---

## 🏗️ Ediciones de Factory I/O
Cada edición está diseñada para diferentes escenarios de entrenamiento y validación:

*   💎 **Ultimate Edition:** Acceso completo a todos los drivers y funcionalidades sin restricciones.
*   🔋 **Siemens Edition:** Orientada a PLCs Siemens vía Ethernet (LOGO!, S7-1200/1500) y simuladores como S7-PLCSIM.
*   🎛️ **Allen-Bradley Edition:** Enfocada en PLCs ControlLogix, CompactLogix, Micro800 y MicroLogix.
*   📡 **Modbus & OPC Edition:** Conexión mediante protocolos universales (Modbus TCP/IP y OPC DA/UA).
*   📋 **MHJ Edition:** Integraciones específicas para SoftPLC Siemens y programación con Grafcet.
*   📝 **Automgen Edition:** Diseño de controladores utilizando GRAFCET y SysML.
*   🚀 **Starter Edition:** Incluye un PLC integrado básico para iniciarse sin hardware externo.

---

## 🔌 Configuración de Comunicación
Los protocolos permiten que el simulador interactúe con PLCs reales, runtimes o softPLCs. ⚙️

La configuración se realiza desde el menú de **Drivers**:
1.  **Selección:** Se elige el driver o protocolo adecuado.
2.  **Parámetros:** Se configuran direcciones IP y puertos.
3.  **Mapeo:** Se vinculan las variables de E/S (sensores y actuadores) entre la escena 3D y el controlador.

Esto permite validar la lógica de control en condiciones muy similares a una planta real. 📊

---

## 📋 Protocolos Utilizados y Equipos Compatibles

*   **Modbus TCP/IP:** 🔗 Compatible con PLCs Modbus, CODESYS, sistemas SCADA y dispositivos IoT. ¡Cualquier dispositivo que soporte Modbus!
*   **OPC Client DA:** 💾 Sistemas SCADA o PLCs/softPLC mediante OPC Data Access.
*   **OPC Client UA:** 🌐 PLCs, servidores de datos o sistemas IIoT con soporte OPC UA.
*   **Ethernet (TCP/IP estándar):** 🖥️ Conexión directa a PLCs Siemens, Allen-Bradley y otros equipos industriales.
*   **Control I/O / SoftPLC:** 🧩 Controladores softPLC integrados o externos con interfaces de E/S específicas.
