# ⚡ Guía de Comandos y Combinaciones de Teclas en EPLAN

Esta guía rápida contiene los atajos de teclado esenciales para optimizar el flujo de trabajo en el diseño electrotécnico y la edición de proyectos dentro de EPLAN.

---

## 🔍 Navegación y Zoom

* 🖥️ Mostrar la página completa ➔ `3`
* ➕ Ampliar zoom un paso ➔ `+`
* ➖ Reducir zoom un paso ➔ `-`
* 🔍 Abrir zoom ➔ `Z`
* 🔄 Actualizar vista ("Redibujar") ➔ `F5`
* 📄 Página siguiente ➔ `Av Pág`
* 📄 Página anterior ➔ `Re Pág`
* 📐 Desplazar encuadre de ventana a la izquierda ➔ `Mayús` + `Tecla de dirección izquierda`
* 📐 Desplazar encuadre de ventana a la derecha ➔ `Mayús` + `Tecla de dirección derecha`
* 📐 Desplazar encuadre de ventana hacia arriba ➔ `Mayús` + `Tecla de dirección arriba`
* 📐 Desplazar encuadre de ventana hacia abajo ➔ `Mayús` + `Tecla de dirección abajo`
* 🚪 Cerrar Edición gráfica ➔ `Ctrl` + `F4`

---

## 🎯 Control de Cursor y Coordenadas

* 📍 Saltar a los puntos de elemento de los elementos seleccionados ➔ `Tab`
* 🧭 Mover el cursor al margen izquierdo de la pantalla ➔ `Inicio`
* 🧭 Mover el cursor al margen derecho de la pantalla ➔ `Fin`
* 🔝 Saltar al margen superior de la pantalla ➔ `Ctrl` + `Inicio`
* 🧲 Saltar al margen inferior de la pantalla ➔ `Ctrl` + `Fin`
* 🔢 Introducción de coordenadas ➔ `P`
* 📊 Introducir coordenadas relativas ➔ `Mayús` + `R`
* 🔄 Activar/desactivar desplazamiento del punto de referencia ➔ `O`
* 📏 Ajustar ancho de pasos ➔ `S`
* 🦘 Saltar a la izquierda hasta el siguiente punto de inserción ➔ `Ctrl` + `Tecla de dirección izquierda`
* 🦘 Saltar hacia la derecha hasta el siguiente punto de inserción ➔ `Ctrl` + `Tecla de dirección derecha`
* 🦘 Saltar hacia arriba hasta el siguiente punto de inserción ➔ `Ctrl` + `Tecla de dirección arriba`
* 🦘 Saltar hacia abajo hasta el siguiente punto de inserción ➔ `Ctrl` + `Tecla de dirección abajo`

---

## 🛠️ Edición, Gestión de Objetos y Portapapeles

* 🔲 Definir ventana (área de selección) ➔ `Espacio en blanco`
* 👥 Agrupar elementos ➔ `G`
* 🔄 Duplicar ventana (área de selección) ➔ `D`
* 🖐️ Desplazar ➔ `V`
* 📝 Editar propiedades de objetos ➔ `Ctrl` + `D`
* 📊 Editar en forma de tabla ➔ `Ctrl` + `Q`
* 🔄 Gráfico: rotar ➔ `Ctrl` + `R`
* ❌ Borrar contenido de una ventana (área de selección) ➔ `Supr`
* ↩️ Deshacer último paso ➔ `Ctrl` + `Z` o `Alt` + `Atrás`
* ☑️ Seleccionar todo ➔ `Ctrl` + `A`
* 📋 Copiar elementos en el portapapeles de EPLAN ➔ `Ctrl` + `C`
* 📋 Insertar elementos desde el portapapeles de EPLAN ➔ `Ctrl` + `V`
* ✂️ Cortar elementos y copiarlos en el portapapeles de EPLAN ➔ `Ctrl` + `X` o `Mayús` + `Supr`
* 👁️ Activar/desactivar la visualización de puntos de inserción ➔ `I`
* 👻 Mostrar / ocultar elementos invisibles ➔ `U`
* 🏷️ Desplazar textos de propiedades ➔ `Ctrl` + `B`

---

## ✏️ Inserción de Gráficos y Textos

* 📏 Insertar línea ➔ `Ctrl` + `F2`
* ↩️ Insertar polilínea ➔ `L`
* 🟩 Insertar rectángulo ➔ `R`
* ⚪ Insertar círculo ➔ `K`
* ⬡ Insertar elipse ➔ `E`
* ↪️ Insertar arco sobre punto central ➔ `Ctrl` + `G`
* 🔤 Insertar texto ➔ `T`
* ✍️ Insertar salto de línea ➔ `Ctrl` + `Entrada`
* 📐 Insertar acotación sencilla ➔ `Ctrl` + `Mayús` + `A`

---

## 🔌 Inserción de Componentes, Símbolos y Conexiones

* 🧩 Insertar símbolo ➔ `Insert`
* ⚡ Insertar conexión de dispositivo ➔ `Mayús` + `F3`
* 🛑 Insertar punto de interrupción ➔ `Mayús` + `F4`
* 🏷️ Insertar texto de función de ruta ➔ `Ctrl` + `T`
* 🔗 Interrumpir uniones ➔ `Ctrl` + `Mayús` + `U`

### 📐 Ángulos y Derivaciones (Esquemas)
* 📐 Ángulo (abajo, derecha) ➔ `F3`
* 📐 Ángulo (abajo, izquierda) ➔ `F4`
* 📐 Ángulo (arriba, izquierda) ➔ `F6`
* ┫ Pieza T (abajo) ➔ `F7`
* ┳ Pieza T (arriba) ➔ `F8`
* ┣ Pieza T (derecha) ➔ `F9`
* ┫ Pieza T (izquierda) ➔ `F10`

### ⛓️ Cables y Blindajes
* 🔌 Insertar definición de cable ➔ `Mayús` + `F5`
* 🛡️ Insertar apantallamiento ➔ `Mayús` + `F6`
* 📍 Insertar punto de definición de unión ➔ `Mayús` + `F7`
* 🌉 Insertar puente (conector de cruce) ➔ `Mayús` + `F8`

### 📦 Cajas y Estructuras
* 📦 Dibujar caja de aparato ➔ `Mayús` + `F11`
* 📦 Insertar caja de lugar ➔ `Ctrl` + `F11`

---

## 📂 Macros y Gestión de Páginas

* 📦 Crear macro de símbolos ➔ `B`
* 📦 Insertar macro de símbolos ➔ `Ctrl` + `Insert`
* 🖥️ Crear macro de ventana ➔ `Ctrl` + `F5`
* 🖥️ Insertar macro de ventana ➔ `M`
* 📄 Crear macro de página ➔ `Ctrl` + `F10`
* 📖 Abrir/cerrar navegador de páginas ➔ `F12`
* 🔖 Marcar página ➔ `Ctrl` + `M`
* 📄 Crear página ➔ `Ctrl` + `N`
* 🖨️ Imprimir páginas ➔ `Ctrl` + `P`

---

## 🔎 Búsquedas y Herramientas Globales

* 🔍 Abrir función de búsqueda ➔ `Ctrl` + `F`
* 🔀 Función de búsqueda: pasar a la contrapieza ➔ `F`
* 📑 Insertar elementos en la lista de resultados de búsqueda ➔ `Ctrl` + `I`
* ⏭️ Función de búsqueda: Saltar a la entrada siguiente ➔ `Ctrl` + `Mayús` + `F`
* ⏮️ Función de búsqueda: Saltar a la entrada anterior ➔ `Ctrl` + `Mayús` + `V`
* 🗺️ Ir a (Gráfico) ➔ `Ctrl` + `J`
* 📊 Edición global: editar datos de proyecto de evaluación ➔ `Ctrl` + `Mayús` + `D`
* 📥 Abrir/cerrar gestión de mensajes ➔ `Ctrl` + `Mayús` + `E`
* 🗄️ Abrir/cerrar navegador de construcción de armarios ➔ `Ctrl` + `Mayús` + `M`

---

## ❓ Sistema

* ❓ Abrir ayuda contextual ➔ `F1` o `Ctrl` + `F1`
* ❌ Cancelar operación ➔ `Esc`
* 🗔 Cambiar entre ventanas abiertas (editor gráfico, navegadores, etc.) ➔ `Ctrl` + `F12`
