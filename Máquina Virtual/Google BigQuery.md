# Gestión de Datos en Google BigQuery 📊☁️

Este documento resume las operaciones realizadas en **Google BigQuery** para la gestión, consulta y análisis de datos.

## 1. Exploración de Datos 🔍
* **Acceso a Dataset:** Se realizó la navegación a través de la consola de BigQuery para localizar conjuntos de datos específicos (*datasets*).
* **Inspección de Esquemas:** Se verificó la estructura de las tablas, incluyendo nombres de columnas, tipos de datos y detalles de configuración para asegurar que la información estuviera lista para ser procesada.

## 2. Ejecución de Consultas (SQL) 💻
* **Redacción de Sentencias SQL:** Se utilizaron comandos SQL estándar (`SELECT`, `FROM`, `WHERE`) dentro del editor de consultas de BigQuery para filtrar y analizar información específica.
* **Resultados:** Las consultas permitieron extraer *insights* de los datos almacenados, con una ejecución eficiente y resultados visualizados directamente en la consola.

## 3. Gestión y Configuración ⚙️
* **Detalles de Proyecto:** Se validó la configuración del proyecto en la nube para asegurar que los permisos y las rutas de acceso a los datos fueran correctos.
* **Monitoreo:** El uso de las herramientas de consulta integradas permitió una gestión ágil, facilitando el análisis de grandes volúmenes de datos sin necesidad de configuraciones de infraestructura complejas.

# Análisis de Datos en Google BigQuery 📊☁️

Este documento sintetiza las operaciones técnicas de análisis de datos realizadas en la consola de Google BigQuery.

## 1. Estructura y Exploración 🔍
* **Navegación de Datasets:** Se exploró la jerarquía de proyectos, *datasets* y tablas en BigQuery.
* **Inspección de Esquemas:** Se revisaron los metadatos de las tablas, incluyendo tipos de columnas (STRING, INTEGER, TIMESTAMP, etc.) para comprender la naturaleza de la información almacenada.

## 2. Consultas y Manipulación SQL 💻
* **Ejecución de Queries:** Se utilizaron sentencias `SELECT`, `JOIN` y funciones de agregación para realizar consultas sobre grandes volúmenes de datos.
* **Filtrado y Análisis:** Se aplicaron condiciones `WHERE` y otros operadores para segmentar datos y obtener métricas relevantes para la toma de decisiones.
* **Validación de Resultados:** Se confirmó la integridad de los resultados obtenidos tras ejecutar las sentencias SQL directamente en la consola.

## 3. Optimización y Visualización 📈
* **Eficiencia de Consultas:** Se observó el uso del motor de consultas de BigQuery para procesar datos de forma rápida.
* **Integración:** El flujo de trabajo demuestra cómo preparar los datos para su posterior visualización o exportación a herramientas de *Business Intelligence* (como Looker Studio o Grafana).
