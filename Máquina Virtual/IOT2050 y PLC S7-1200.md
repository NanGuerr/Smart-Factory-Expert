# Configuración PLC S7-1200 y IOT2050 con Linux ⚙️🐧

Este documento resume el proceso de puesta en marcha del dispositivo de borde (Edge Gateway) **Siemens IOT2050**, su configuración de red y su integración con un **PLC S7-1200**.

## 1. Configuración de Hardware y Conectividad 🔌
* **Dispositivo:** Siemens IOT2050 (Edge Gateway), diseñado para aplicaciones industriales.
* **Red:** Se configuró una conexión de red local (LAN) para establecer comunicación entre el PC del desarrollador, el IOT2050 y el autómata programable.
* **Interfaz:** Uso de PuTTY para gestionar conexiones remotas mediante protocolo SSH, permitiendo administrar el sistema operativo del gateway desde una terminal externa.

## 2. Sistema Operativo: Debian Linux 🐧
* **Entorno:** Se verificó la ejecución de una distribución de **Debian Linux** optimizada para el hardware IOT2050.
* **Gestión:** El uso de Linux permite una gran flexibilidad para instalar servicios adicionales (como Node-RED, bases de datos o agentes de monitorización), convirtiendo el dispositivo en un nodo de procesamiento de datos inteligente.

## 3. Integración con PLC S7-1200 🤖
* **Arquitectura:** El IOT2050 actúa como puente o pasarela entre el mundo industrial (PLC S7-1200) y los sistemas de nivel superior o nube.
* **Flujo de datos:** El IOT2050 se encarga de recolectar, procesar y eventualmente transmitir la información del proceso industrial, permitiendo la digitalización de la planta sin interrumpir las funciones de control del PLC.

# Automatización de Flujos de Datos Industriales (Node-RED, WinSCP y BigQuery) 🔄⚙️

Este documento resume la integración técnica para mover datos desde entornos industriales (Siemens IOT2050) hacia la nube (Google BigQuery) utilizando herramientas de automatización y transferencia de archivos.

## 1. Transferencia y Gestión de Archivos (WinSCP) 📂
* **Función:** Se utiliza **WinSCP** como herramienta principal para la transferencia segura de archivos (SFTP/SCP) entre el equipo de desarrollo y el gateway industrial IOT2050.
* **Uso técnico:** Permite cargar archivos de configuración, scripts de automatización y las credenciales (archivos `.json` de Google Cloud) necesarias para autenticar los servicios desplegados en el gateway.

## 2. Automatización en el Borde con Node-RED 🤖
* **Orquestación:** Node-RED se despliega en el IOT2050 para crear flujos visuales que conectan los datos del PLC S7-1200 con la nube.
* **Integración con BigQuery:** Se utilizan nodos específicos para procesar datos, formatearlos en JSON y enviarlos hacia las APIs de Google BigQuery. Esto permite que el gateway actúe como un nodo inteligente que transforma protocolos industriales en datos listos para el análisis.
* **Persistencia:** La configuración de los flujos asegura que la recolección de métricas (temperatura, estados de máquinas, etc.) sea continua y fiable.

## 3. Entorno Operativo (Debian Linux) 🐧
* **Estabilidad:** El sistema corre sobre **Debian Linux**, proporcionando la robustez necesaria para ejecutar procesos en segundo plano (*background processes*) y gestionar la comunicación segura mediante claves SSH.
