## 💡 Pregunta 1: Análisis de Operación Lógica
### Con la operación: 
`LD A`
`AND B`
`ANDN C`
`ST Lampara`

**¿Qué estados deben tener las señales A, B y C para que la lámpara se encienda?**

* ⚪ `A = 0; B = 0; C = 1`
* ⚪ `A = 0; B = 1; C = 1`
* ⚫ **`A = 1; B = 1; C = 0` (Respuesta Correcta)**
* ⚪ `A = 1; B = 0; C = 1`
